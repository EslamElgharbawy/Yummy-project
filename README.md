## 📖 About

Yummy is a modern restaurant landing page designed to provide an engaging user experience with elegant UI, responsive layouts, and smooth animations. The project focuses on clean design, accessibility, and fast performance across all devices.

## ✨ Features

- 🍽️ Modern Restaurant Landing Page
- 📱 Fully Responsive Design
- 🎨 Beautiful & Clean User Interface
- ⚡ Smooth Scrolling Navigation
- 🍔 Menu Section
- 👨‍🍳 Professional Chefs Section
- 🖼️ Interactive Gallery
- ⭐ Testimonials Section
- 📅 Book a Table Form
- 📍 Contact Section

- 🚀 Optimized Performance
